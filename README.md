# Trilha DevOps

Trilha de estudo de DevOps em português, do zero à vaga remota internacional: 17 fases com aulas escritas, leituras gratuitas, nivelamento, laboratórios, perguntas de entrevista e dados de mercado.

É um site estático: abra o `index.html` ou acesse pelo GitHub Pages. O progresso fica no navegador e pode ser sincronizado entre aparelhos por um Gist privado (página **Sincronizar**).
